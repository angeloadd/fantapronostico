# Step 2: Laravel 11 → 13 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the Laravel framework from 11 to 13 and bring all Laravel ecosystem packages to compatible versions, including a Filament 3 → 4 bump (admin panel correctness is deferred).

**Architecture:** PHP/Composer-only changes. No JS or CSS changes. The app must boot and pages must render at the end. Filament UI correctness is explicitly out of scope for this step.

**Tech Stack:** Laravel 13, PHP 8.5 (already in place from Step 1), Filament 4, Laravel Fortify, Composer

> ⚠️ **Review gate:** Do NOT commit at any point without first presenting the diff to the user and receiving explicit approval.

### Task 3: Apply Laravel 13 bootstrap and config changes

**Files:**
- Review: `bootstrap/app.php`
- Review: `config/app.php`, `config/cache.php`, `config/session.php`

- [ ] **Step 1: Compare bootstrap/app.php against the Laravel 13 skeleton**

The current `bootstrap/app.php` uses the `Application::configure()` API introduced in Laravel 11 — this is unchanged in Laravel 13. No edits needed unless `php artisan about` reports an error.

- [ ] **Step 2: Check config files for deprecated keys**

```bash
php artisan config:clear && php artisan about 2>&1 | tee /tmp/artisan-about.log
cat /tmp/artisan-about.log
```

If any deprecation notices appear, fix the flagged config keys. Common Laravel 13 change: `config/cache.php` and `config/session.php` prefix format changes from `_` to `-` separator. Since this app is not in production, no data migration is needed — just clear any cached values:

```bash
php artisan cache:clear
php artisan session:flush 2>/dev/null || true
```

- [ ] **Step 3: Run framework migrations**

```bash
php artisan migrate 2>&1 | tee /tmp/migrate-step2.log
cat /tmp/migrate-step2.log
```

Expected: any pending Laravel framework migrations run cleanly.
